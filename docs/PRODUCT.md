Goal:
Build a local-first personalized chess coaching system.

Input:
Completed historical Chess.com games / PGN.

Outputs:

- individual game analysis
- recurring weakness detection
- phase analysis
- opening analysis
- personalized coaching
- personalized puzzles
- improvement tracking

Constraints:

- post-game only
- local chess analysis
- local LLM
- zero inference cost
- no duplicated games
- no repeated analysis without reason
- explainable/traceable coaching

NOT V1:

- live game assistance
- multiplayer chess
- social network
- mobile app
- authentication
- cloud hosting
- payments
- fancy UI
- training our own LLM
- training our own chess engine
- Chess.com visual clone
